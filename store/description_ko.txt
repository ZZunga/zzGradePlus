[제목]
zz경사도+ - 경사도, 고도, 획득고도

[소개글]
큰 숫자로 현재 경사도(%)를 보여주는 데이터 필드입니다. 고도, 총 획득고도, 랩 획득고도 중 하나를 함께 표시하고, 오르막과 내리막을 색으로 알려줍니다.
가독성 향상을 위해 TitilliumWeb 폰트를 사용하여 제작되었습니다.
기존 zz경사도를 새로 만든 앱입니다.

[경사도]
- 3초마다 달린 거리와 고도 변화로 계산하고, 설정한 구간(3~15초)으로 평균을 냅니다.
- 멈췄다 다시 출발해도 바로 실제 경사도를 표시하고, 정지 중에는 마지막 경사도를 유지합니다.
- 10% 미만은 소수 한 자리, 10% 이상은 정수로 표시합니다.
- 경사도를 활동 기록에 저장해 Garmin Connect에서 그래프로 볼 수 있습니다.

[보조값]
- 고도 / 총 획득고도 / 랩 획득고도 / 없음
- 단위는 기기 설정(m 또는 ft)을 따릅니다.
- 메인 값(큰 글씨)과 두 번째 값(작은 글씨)을 각각 고릅니다. 둘 다 경사도 / 고도 / 총 획득고도 / Lap 획득고도 중에서 고를 수 있습니다.
- 두 값이 같으면 두 번째 값이 자동으로 바뀝니다.
- 두 번째 값을 "없음"으로 두면 메인 값만 크게 표시합니다.

[색상 표시]
- 경사도가 기준값(기본 1%)을 넘으면 오르막 색, -기준값보다 낮으면 내리막 색으로 바뀝니다.
- 오르막과 내리막 색을 주간/야간 따로 고를 수 있습니다.

[배경색]
- 기기 설정(흰색 / 검정)을 따릅니다. 설정에서 세 가지 중에 고를 수 있습니다.
- 검정 · 흰색 그대로 (기본) / 기기 화면색에 맞춤 / 투명
- 투명은 배경을 아예 칠하지 않아 기기 배경이 그대로 비칩니다. 데이터 필드 배경이 다른 화면과 조금 달라 보이면 투명으로 바꿔 보세요.

[칸 크기에 맞춘 자동 배치]
- 10칸 레이아웃의 한 칸: 위쪽에 경사 아이콘과 보조값, 아래쪽에 경사도를 크게 표시합니다.
- 가로로 넓은 칸: 위쪽에 zzGrade+ 제목과 표시 중인 값, 아래쪽에 두 값을 나란히 표시합니다. 5자리 획득고도도 들어갑니다.
- 다른 Plus 데이터 필드와 같은 글꼴, 같은 크기, 같은 배치를 사용해 함께 쓰면 화면이 일관되게 보입니다.

Edge 540 / 550 / 840 / 850 / 1040 / 1050 / 1060
